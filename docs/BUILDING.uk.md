# Сповіщення ДТЕК для будинку

[English](BUILDING.md) · **Українська** · [Встановити застосунок](../README.uk.md#installation)

Оберіть **Графіки за адресою**, щоб отримувати сповіщення для будинку без входу до кабінету ДТЕК. Надсилайте їх у групу, канал або лише собі. Один профіль стежить за однією адресою та надсилає повідомлення одному одержувачу.

Для групи квартири з кабінету, історії та передачі показів оберіть [особистий режим](PERSONAL.uk.md). Обидва режими можуть працювати в одному застосунку та через одного Telegram-бота.

## Перед початком

- Встановіть [DTEK Monitor](https://groove-max.github.io/ha-dtek-monitor/uk/installation/), додайте адресу будинку й перевірте, що її сутності завантажилися в HA. Вхід до кабінету необов’язковий.
- [Встановіть цей застосунок](../README.uk.md#installation) і введіть токен бота, створеного через [@BotFather](https://t.me/BotFather).
- Оберіть одержувача. Для особистого чату відкрийте свого бота й натисніть **Start**. Для групи додайте бота та дозвольте повідомлення. Для каналу надайте права адміністратора на публікацію й редагування. Закріплення у спільних чатах потребує відповідних прав.

## Підключіть будинок і чат

1. Відкрийте вебінтерфейс застосунку → **Налаштування → Додати профіль**.
2. Оберіть **Графіки за адресою** і свій будинок. Задайте коротку назву, зрозумілу сусідам.
3. Залиште вибір групи порожнім, щоб стежити за **всіма групами будинку**. Обирайте одну лише тоді, коли потрібні повідомлення саме для неї.
4. На кроці **Telegram** оберіть бота й одержувача. Надішліть `/start` особисто або `/start@ім’я_бота` у групі, потім натисніть **Оновити**. Канал з’явиться після нового допису або зміни участі бота, отриманої через Telegram. [Пошук одержувачів і ручне введення ID](../DOCS.uk.md#telegram).
5. Оберіть сповіщення та, за бажанням, [датчики живлення](POWER.uk.md). Для графіків датчики не потрібні.
6. Перевірте чат і параметри, натисніть **Застосувати**. Це перевірить і збереже конфігурацію та перезапустить застосунок.

Список одержувачів використовує нові події Telegram; він не може показати всі чати, до яких колись додавали бота. **Приймання команд** має бути ввімкнено на HA, що збирає ці події. Один токен може мати лише один збирач вхідних повідомлень. [Один бот на кількох серверах](PERSONAL.uk.md#один-токен-на-кількох-ha).

## Оберіть корисні сповіщення

| Сповіщення | Що отримають сусіди |
| --- | --- |
| Зміна графіка | Оновлений перевірений графік для груп будинку. |
| Зміна групи | Підтверджена зміна груп, призначених адресі. |
| Завчасне попередження | Нагадування перед найближчим перевіреним відключенням; час обираєте ви. |
| Стан за даними ДТЕК | Причина й орієнтовний час відновлення від оператора. |
| Фактичне зникнення й повернення світла | Переходи стану за придатними датчиками, якщо їх налаштовано. |
| Якість напруги | Необов’язкові сповіщення про низьку/високу напругу та відновлення норми; налаштовуються окремо. |

Увімкніть лише потрібні цьому чату повідомлення. Графік описує план і не підтверджує фактичну наявність світла. Якщо графік відсутній або не опублікований, сповіщення за ним призупиняються, а не повідомляють про відсутність відключень. Контроль за датчиками може працювати незалежно.

## Залиште один актуальний статус

Увімкніть **Статусне повідомлення**, оберіть **редагування наявного повідомлення** (`pinned_edit`) і закріплення, якщо воно потрібне. Бот оновлюватиме власний статус із групами, живленням, напругою та найближчим перевіреним відключенням. Автоматичні сповіщення залишаються окремими повідомленнями.

Без закріплення можна оновлювати одне звичайне повідомлення. Якщо статус дублюється або не закріплюється, перевірте права бота. Втрата датчика показується як невідомий стан; окремі повідомлення про втрату телеметрії типово вимкнені.

Повідомлення й редактор типово українською. Змінюйте формулювання в [Шаблонах](../DOCS.uk.md#templates), зокрема привітання для нових особистих користувачів. Дані кабінету й передача показів доступні лише авторизованому користувачеві приватного профілю, а не в будинковому чаті.

## Кілька будинків, чатів або ботів

- Додайте інший профіль для іншої адреси.
- Скористайтеся **Клонувати**, щоб надсилати той самий будинок іншому одержувачу з незалежними параметрами й історією доставки.
- Оберіть іншого бота на кроці Telegram, якщо потрібні окремі ім’я та токен. Кілька профілів можуть використовувати один токен.

Друге встановлення застосунку не потрібне. Профілі налаштовує адміністратор HA; повідомлення боту не створює підписку на будинок автоматично. [Профілі, одержувачі й токени](../DOCS.uk.md#destinations).

## Перевірте доставку до запуску спільного чату

Спочатку перевірте одержувача. За потреби задайте [тестовий чат](../DOCS.uk.md#testing) і надішліть позначений тест шаблону собі або в тестову групу. Тест надсилає справжнє повідомлення. Не використовуйте групу мешканців для експериментів.

Перевірте **Поточний стан** у редакторі: з’єднання з HA, правильну адресу/групи й одержувача. Неопублікований графік або відсутній фізичний датчик можуть правомірно показувати недоступні чи невідомі дані.
